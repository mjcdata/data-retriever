# U.S. Daily Weather — Project Proposal

## Objective
Build a trustworthy, updateable daily weather dataset covering the United States for use in future weather forecasting and predictive modeling.

## Initial scope
- Geography: United States
- Historical window: approximately 10 years
- Grain: daily weather observations
- Update requirement: support repeatable retrieval of the latest available observations
- Intended prediction targets: temperature, precipitation, snowfall, and other useful daily weather measures supported by the selected authoritative source

## Data integrity
Source selection, field definitions, missingness, transformations, validation, and limitations will be documented. No unavailable values or metadata will be fabricated.

## Storage
Storage will be selected after source discovery and dataset-size assessment. GitHub will retain the project structure, documentation, retrieval/processing code, provenance, and reproduction instructions. Large or frequently updated data will not automatically be committed to GitHub.

## Approval gate
No full data retrieval should begin until the owner approves this proposal and the accompanying project plan.
